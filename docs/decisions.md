# Decisions

Which libraries octo-translator uses, the patterns the code follows, and the rules that keep the page and the user's
data safe.

## Libraries

| Area                            | Candidates                                      | Decision                              | Reason                                                                                                                                                                                                                                  |
| ------------------------------- | ----------------------------------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Extension build and manifest    | WXT, CRXJS Vite plugin, plain Vite              | WXT                                   | Generates the MV3 manifest from the entry points, reloads during development, zips for the store, and ships typed `browser` and `storage` wrappers. Auto-imports are off (`imports: false`).                                            |
| Gemini client                   | `@google/genai`, `fetch`                        | `fetch` (`src/lib/gemini.ts`)         | One request to one endpoint; the SDK would add most of the background bundle for it. The response is checked with Valibot.                                                                                                              |
| Input and response validation   | Valibot, Zod, own code                          | Valibot                               | Messages between the content script and the background, the Gemini response and the translations it carries are schemas; Valibot is small and already used the same way in the owner's other repositories.                              |
| Storage                         | `chrome.storage` directly, WXT `storage`        | WXT `storage` (`src/lib/settings.ts`) | Typed items with fallbacks and `watch`, already part of WXT.                                                                                                                                                                            |
| Hashing the cached segments     | Hash libraries, Web Crypto                      | Web Crypto (`crypto.subtle`)          | SHA-256 is built in.                                                                                                                                                                                                                    |
| HTML sanitizer                  | DOMPurify, own code                             | None                                  | The model's output is never parsed as HTML (see Security), so there is nothing to sanitize.                                                                                                                                             |
| Markdown-to-text for the prompt | Turndown and others, own code                   | Own (`src/lib/segments.ts`)           | The rendered DOM is read directly and rebuilt from clones of its own elements; going through Markdown would lose the elements to put back.                                                                                              |
| Tests                           | Vitest with happy-dom, jsdom, WXT `fakeBrowser` | Vitest with happy-dom                 | The logic takes its dependencies as arguments, so tests need a DOM but no extension APIs.                                                                                                                                               |
| Icons                           | `@primer/octicons`, copied paths                | Copied paths (`src/lib/icons.ts`)     | Two Octicons (MIT) and the shape of Primer's spinner; the package would bundle every icon into the content script.                                                                                                                      |
| Translation prompt              | yomiyasu as a whole, a short prompt             | A short prompt in `src/lib/gemini.ts` | It is sent with every request. It keeps the rules of yomiyasu's PR and technical-writing guides that apply to a translation (noun endings for headings and items, no added facts, no literal English phrasing) and leaves out the rest. |

## Patterns

| Concern     | Pattern                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Results     | A discriminated union, `{ ok: true, ... }` or `{ ok: false, code }`, with the code from a closed set (`TRANSLATION_ERRORS`). User-facing text for each code is a `Record` table in `controller.ts`.                                                                                                                                                                                                                                                                                                           |
| GitHub DOM  | Every selector is in `src/lib/pr-page.ts`. GitHub changes its markup without notice; a broken selector is fixed there.                                                                                                                                                                                                                                                                                                                                                                                        |
| Controls    | `src/lib/controls.ts` builds them from GitHub's own classes: a button among the description's header actions (`aria-pressed` while the translation shows, a spinner while it is requested), a note on the header's "commented" line like GitHub's "edited", and a `flash-warn` above the description on errors. A visually hidden `role="status"` announces each change. Without the header actions, a notice above the description carries all of it. Spinners are not `octicon`s: GitHub's CSS fills those. |
| Page sync   | `PageController.sync` is idempotent and runs once per animation frame after any mutation. It compares the page with its state and changes only what differs, so GitHub's re-renders and its own changes settle.                                                                                                                                                                                                                                                                                               |
| React nodes | The title belongs to GitHub's React tree. Its nodes are never replaced or edited: a copy carrying the translation is placed next to it and the original is hidden.                                                                                                                                                                                                                                                                                                                                            |
| Rails nodes | The description is server-rendered. Its inline runs are swapped with translated nodes, and the original nodes are kept to swap back.                                                                                                                                                                                                                                                                                                                                                                          |
| Boundaries  | The content script reads the page and settings; the background holds the API key, the cache and the only network request. Messages are Valibot schemas in `src/lib/messages.ts`, checked on both sides.                                                                                                                                                                                                                                                                                                       |
| Testability | Modules under `src/lib` take their dependencies (`fetch`, storage, the translate call) as arguments; the entry points under `src/entrypoints` only wire them to the extension APIs.                                                                                                                                                                                                                                                                                                                           |

## Security and privacy

- **No HTML from the model.** A pull request's text is attacker-controlled, and so is what the model returns about it.
  Inline elements travel as numbered markers; the translated nodes are clones of the page's own elements whose text is
  set with `textContent`. A translation whose markers do not match the source is dropped and the original stays.
  Pinned by `src/lib/segments.test.ts`.
- **The key stays in the background.** The API key is in `storage.local` (not `storage.sync`), is sent only to
  `generativelanguage.googleapis.com` in the `x-goog-api-key` header, and never appears in a URL. The background
  answers only messages from this extension. Pinned by `src/lib/gemini.test.ts`.
- **Private repositories opt in.** The free tier may use what it is sent to improve Google's products. A repository
  counts as public only when GitHub's page says so; anything else needs an entry in the options. Pinned by
  `src/lib/controller.test.ts`.
- **Limits.** One request per pull request and text version, shared by callers that ask while it is in flight; at
  most 40,000 characters of source text; a 120-second timeout; `store: false` so the interaction is not kept on
  Google's side; and at most 5 MB of cached translations, half of `storage.local`, newest first. A failed cache write
  still answers the translation. Pinned by `src/lib/translate-service.test.ts`.
