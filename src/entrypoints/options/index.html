Octo Translator の設定

深くすると訳が自然になることがありますが、時間と費用がかかります。選べるのはモデルが対応している深さだけです。

オフのときは、本文の上の「日本語に翻訳」を押したときだけ翻訳します。翻訳済みの内容は保存され、本文が変わるまで再度は送りません。

1 行に 1 つ、owner/repo の形で書きます。翻訳する内容は選んだサービスに送られ、サービスによっては保存や学習に使われることがあるため、非公開リポジトリはここに書いたものだけを翻訳します。

Worker（任意）

自分で動かしている Cloudflare Worker を通して翻訳します。Worker に接続できないときは、上の API キーでこのブラウザーから翻訳します。Worker が要求を断ったときは翻訳しません。

https:// で始まり、パスのない URL です。空にすると Worker を使いません。保存するときに、この URL への接続の許可を求めます。

Worker を守る Cloudflare Access のサービストークンです。このブラウザーにだけ保存され、上の URL への送信にだけ使います。
